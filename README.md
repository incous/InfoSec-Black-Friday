A community-maintained list of InfoSec-related deals for Black Friday and Cyber Monday 2026.

This repo was created and maintained for many years by **Mike Monnik ([@securitymeta_](https://twitter.com/securitymeta_))**, who built and vetted this list year after year. Some honest expectations:

- I'm starting late (Black Friday is only days away). This is a best-effort, personal-notes-style list that I'm sharing in case it's useful. Use whatever helps.
- If the original maintainer comes back, I'm happy to hand the repo back and point everyone to the original list.
- Past editions are kept as-is as archives. The previous year's list is in [`2025.md`](2025.md).

## What's in this repo

Deals relevant to people working in (or learning) information security: pentesters, red/blue/purple teamers, AppSec/DevSecOps, DFIR, threat intel/OSINT, GRC, security awareness, and anyone who wants to get into the field.

How it's organised:

- **`README.md`** - the current year's list (2026). Start here.
- **`20XX.md`** - archives of previous years' lists.
- Within the list, deals are grouped by category (e.g. Tools, Online Courses & Training, Practical Labs, Exams, Hardware, Books, Services, Misc). Each entry follows the same shape:

  ```
  **Vendor** - short description \
  https://vendor.example/deal  
  50% off with code `CODE` \
  Deal ends: 2nd December
  ```

Notes on reading it:

- Prices are USD unless stated; end times are UTC unless stated.
- Always check the vendor's own page. Deals change and expire, and I can't verify everything.
- **DYOR / AYOR:** I try to sanity check links, but there's always a chance something slips through. Be careful with links and codes from any list.
- No affiliate links.

> **Status:** the 2026 list is empty so far. Deals will be added as they're submitted/verified. Check back, or contribute one!

## Contributing a deal

Contributions are very welcome. The easiest way is a pull request:

1. **Fork** this repo.
2. In your fork, **edit `README.md`** and add your deal under the right category (use the format above).
3. **Commit** and open a **pull request** against this repo.
4. In the PR description, include **a source** (vendor page, announcement or email) and the **coupon code** if there is one.

If you'd rather not use git, open an issue with the same details.

What makes a good submission:

- It's **InfoSec related**.
- The deal is **active or on a waitlist**, with a **start/end date** if known.
- You include a **link and code**; no unverifiable, one-time or gated deals.
- No affiliate or referral links.
- Be wary of "too good to be true" claims (e.g. 90%+ off, or $100 for a $1000+ product).

Formatting tips:

- Bold the vendor/product name: `**Name**`.
- Put coupon codes in backticks: `` `CODE` ``.
- End a line with `\` for a line break, and use two trailing spaces after a link.
